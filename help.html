Справка по расширению

Это расширение для браузера Chrome предназначено для автоматизации взаимодействия с веб-страницами, упрощения работы с DOM-элементами и копирования селекторов и значений. Оно полезно для веб-разработчиков, тестировщиков и всех, кто хочет автоматизировать повторяющиеся задачи.

1. Контекстное меню для копирования селекторов и значений

Расширение добавляет в контекстное меню браузера (по правому клику) следующие опции:

  • Copy CSS Selector: Копирует CSS-селектор активного элемента.
    • Генерирует уникальный селектор, начиная с ID (если есть) или используя теги с модификатором :nth-of-type.
    • Отображает всплывающее уведомление с скопированным селектором.
  • Copy XPath: Копирует XPath-путь активного элемента.
    • Создает путь, начиная с ID или используя индексацию тегов.
    • Показывает уведомление с скопированным XPath.
  • Copy Value: Копирует значение активного элемента.
    • Для <select> показывает панель с опциями для выбора значения.
    • Для <input type="radio"> отображает панель с радиокнопками.
    • Для других элементов копирует value или textContent.
    • Уведомление подтверждает копирование.
  • Copy Selector Variants: Показывает список различных селекторов для элемента.
    • Включает CSS и XPath на основе ID, классов, атрибутов (name, type, title, placeholder, data-*), позиции (:nth-of-type) и текста (contains(text)).
    • Позволяет выбрать и скопировать нужный селектор из панели.

2. Автоматизация действий на веб-страницах

Расширение позволяет создавать, сохранять и выполнять правила для автоматизации действий на страницах, соответствующих заданным URL-шаблонам.

Создание и управление правилами

  • Правила организованы в группы с названиями.
  • Каждое правило включает:
    • Название (title).
    • URL-шаблон (поддерживает * для любых символов и # для цифр).
    • Флаг автозапуска (autoRun).
    • Список шагов (steps) с действиями.

Типы шагов

  • fill: Заполняет элемент значением.
    • Для <input> (включая checkbox, radio) устанавливает значение или состояние.
    • Для <select> выбирает опцию по значению или тексту.
    • Для других элементов изменяет textContent.
    • Поддерживает подстановку из query-параметров (q{key}).
  • click: Выполняет клик по элементу (CSS или XPath).
  • wait: Ожидает заданное время (в секундах).
  • blockAlert: Блокирует вызовы window.alert.
  • setConfirm: Задает значение для window.confirm (0 = OK, 1 = Cancel).
  • setPrompt: Задает значение для window.prompt.

Селекторы

  • Поддерживаются CSS и XPath селекторы.
  • Можно указать несколько селекторов для шага; используется первый найденный элемент.

Автозапуск

  • Правила с autoRun: true выполняются автоматически при загрузке страницы, если URL соответствует шаблону.
  • При наличии нескольких подходящих правил пользователь выбирает одно через всплывающее окно.

Query-параметры

Значения из URL-параметров (начинающихся с __ext_) подставляются в шаги (например, q{param} для ?__ext_param=value).

3. Интерфейс управления правилами

  • Добавление/редактирование: Создание групп, правил и шагов с указанием названий, URL, селекторов и значений.
  • Импорт/экспорт: Экспорт правил в autofill_rules.json и импорт из JSON с проверкой структуры.
  • Автосохранение: Изменения сохраняются в chrome.storage.local с небольшой задержкой.
  • Удаление/дублирование: Поддерживается удаление и копирование групп, правил и шагов.

4. Перехват диалоговых окон

  • alert: Может блокироваться (шаг blockAlert), сообщения записываются в консоль.
  • confirm: Возвращает заданное значение (0 = OK, 1 = Cancel) через шаг setConfirm.
  • prompt: Возвращает заданное значение через шаг setPrompt, включая подстановку из query-параметров.

5. Всплывающее окно (Popup)

  • Выбор правила: Позволяет выбрать и выполнить правило на активной вкладке.
  • Настройки: Открывает страницу управления правилами.
  • Если правил нет, отображается сообщение об их отсутствии.

6. Технические особенности

  • Скрипты:
    • content.js: Управляет контекстным меню, выполнением правил и инъекцией injected.js.
    • injected.js: Перехватывает alert, confirm, prompt.
    • options.js: Интерфейс настроек.
    • popup.js: Управляет всплывающим окном.
  • Хранение данных: Правила хранятся через chrome.storage.local.
  • Уведомления: Toast-уведомления для копирования и действий, уведомления в настройках и popup.
  • Логирование: Используется console.debug для отладки.

Примечание: Это расширение идеально подходит для автоматизации повторяющихся задач, тестирования веб-приложений и упрощения работы с DOM. Для настройки правил откройте страницу настроек через всплывающее окно.

Примеры использования и создание правил для расширения

Этот документ дополняет основную справку и содержит примеры использования расширения, а также рекомендации по созданию правил для автоматизации действий на веб-страницах.

1. Примеры использования

Ниже приведены практические примеры, демонстрирующие, как использовать функции расширения для копирования селекторов, значений и автоматизации задач.

Пример 1: Копирование CSS-селектора и XPath для элемента

Допустим, вы хотите получить селектор для текстового поля на странице формы.

  1. Перейдите на веб-страницу с формой (например, https://example.com/form).
  2. Кликните правой кнопкой мыши на текстовом поле (например, <input id="username">).
  3. Выберите Copy CSS Selector. Расширение скопирует селектор, например: #username.
  4. Выберите Copy XPath. Расширение скопирует XPath, например: //*[@id="username"].
  5. После копирования появится уведомление с текстом селектора, например: Copied: #username.

Использование: Полученные селекторы можно использовать в скриптах автоматизации (например, Selenium) или для создания правил в расширении.

Пример 2: Копирование значения из выпадающего списка

Вы хотите скопировать значение из элемента <select> на странице.

  1. Кликните правой кнопкой мыши на выпадающем списке (например, <select name="country">).
  2. Выберите Copy Value.
  3. Появится панель с доступными опциями (например, USA (us), Canada (ca)).
  4. Кликните на нужную опцию, чтобы скопировать её значение (например, us).
  5. Уведомление подтвердит: Copied: us.

Использование: Это удобно для тестирования или извлечения данных из форм.

Пример 3: Автоматизация заполнения формы

Вы хотите автоматически заполнить форму на странице https://example.com/login с логином и паролем.

  1. Откройте страницу настроек расширения (через всплывающее окно, нажав на ссылку "Настройки").
  2. Создайте новую группу, например, Авторизация.
  3. Добавьте правило с названием Логин на example.com и URL-шаблоном https://example.com/login.
  4. Добавьте два шага:
    • Шаг 1: Тип fill, селектор #username (CSS), значение myuser, описание Заполнить логин.
    • Шаг 2: Тип fill, селектор #password (CSS), значение mypassword, описание Заполнить пароль.
  5. Установите флаг Автозапуск для автоматического выполнения.
  6. Сохраните правило и перейдите на https://example.com/login. Поля логина и пароля будут автоматически заполнены.

Использование: Это экономит время при тестировании или частом заполнении форм.

Пример 4: Блокировка alert и установка значения confirm

На странице появляется раздражающий alert, и вы хотите его заблокировать, а также автоматически ответить на confirm.

  1. Создайте правило для URL, например, https://example.com/prompt-page.
  2. Добавьте шаги:
    • Шаг 1: Тип blockAlert, без селектора, описание Блокировать alert.
    • Шаг 2: Тип setConfirm, значение 0 (для OK), описание Подтвердить действие.
  3. Включите автозапуск и сохраните.
  4. При загрузке страницы alert будет заблокирован, а confirm автоматически вернёт OK.

Использование: Полезно для автоматизации тестов, где диалоговые окна мешают процессу.

Пример 5: Использование query-параметров

Вы хотите заполнить поле формы значением из URL, например, https://example.com/form?__ext_user=john.

  1. Создайте правило с URL-шаблоном https://example.com/form*.
  2. Добавьте шаг:
    • Тип fill, селектор #username (CSS), значение q{user}, описание Заполнить имя из URL.
  3. Сохраните и откройте страницу https://example.com/form?__ext_user=john.
  4. Поле #username будет заполнено значением john.

Использование: Удобно для динамического заполнения форм на основе параметров URL.

2. Как правильно создавать правила

Создание эффективных правил требует понимания структуры веб-страницы и правильного использования селекторов. Вот пошаговые рекомендации:

Шаг 1: Определите цель

  • Решите, какие действия вы хотите автоматизировать (например, заполнение формы, клик по кнопке, блокировка диалогов).
  • Определите URL страницы, на которой будет выполняться правило.

Шаг 2: Получите селекторы

  • Используйте контекстное меню (Copy CSS Selector, Copy XPath, или Copy Selector Variants) для получения селекторов целевых элементов.
  • Проверьте селекторы:
    • Для CSS: используйте document.querySelector("селектор") в консоли браузера.
    • Для XPath: используйте document.evaluate("селектор", document, null, XPathResult.FIRST_ORDERED_NODE_TYPE, null).singleNodeValue.
  • Выбирайте наиболее надёжные селекторы:
    • Предпочтительно использовать ID (#id или //*[@id="id"]).
    • Если ID нет, используйте уникальные классы или атрибуты.
    • Избегайте длинных путей, зависящих от структуры DOM, так как она может измениться.

Шаг 3: Создайте группу и правило

  • Откройте настройки расширения.
  • Создайте группу (например, Тестирование форм).
  • Добавьте правило, указав:
    • Название: Описательное название, например, Заполнение формы логина.
    • URL-шаблон: Используйте маски:
      • * — любой набор символов (например, https://example.com/*).
      • # — цифры (например, https://example.com/page/#).
    • Автозапуск: Включите, если правило должно выполняться автоматически.

Шаг 4: Добавьте шаги

  • Для каждого действия добавьте шаг с типом (fill, click, wait, и т.д.).
  • Укажите селектор (CSS или XPath) и значение (если требуется).
  • Пример шага для заполнения: 
    {
  "type": "fill",
  "selectors": [
    { "type": "css", "value": "#username" }
  ],
  "value": "testuser",
  "description": "Заполнить поле логина",
  "enabled": true
}
  • Для динамических значений используйте q{key} с query-параметрами.

Шаг 5: Тестируйте правило

  • Сохраните правило и откройте целевую страницу.
  • Если включён автозапуск, правило выполнится автоматически.
  • Или используйте всплывающее окно (Popup) для ручного выполнения.
  • Проверьте логи в консоли браузера (console.debug) для диагностики ошибок.

Шаг 6: Экспорт и импорт

  • Экспортируйте правила в JSON для резервного копирования или переноса.
  • Импортируйте правила, убедившись, что JSON соответствует структуре (массив групп с правилами и шагами).

Совет: Для сложных страниц используйте Copy Selector Variants, чтобы выбрать наиболее устойчивый селектор. Тестируйте правила на разных сценариях, чтобы учесть возможные изменения DOM.

Примечание: Расширение сохраняет правила в chrome.storage.local. Используйте логи в консоли для отладки и убедитесь, что селекторы уникальны и надёжны.
